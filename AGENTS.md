# Fork installation notes

This is dsh-image-viewer-fl0wer@0.1.17, an MIT modification of WSL043/dsh-image-viewer. Install the pinned release tarball in the selected DSH profile. Preserve unrelated plugins, sessions, settings and credentials. Disable the original viewer first; both share Cordis row ID wsl043-native-image-viewer. Do not restart the host as part of publication. Runtime implementation is readable lib/client.js; inherited upstream build sources are reference only. See README.md and MODIFICATIONS.md.
